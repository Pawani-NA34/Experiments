# 🚀 Bayesian Estimation of Semi-Empirical Mass Formula Parameters using MCMC

Welcome to my repository! This is an **independent project** developed entirely by me, focusing on the parameters correlation and their values in the Semi-Empirical Mass Formula using the MCMC method.

## 📌 Main Project File
The primary file for this project is:
* **`semf1.ipynb`** 

## 📁 Other Files in this Repo
* `ame2020.tsv`: The dataset used for the analysis.
* https://iopscience.iop.org/article/10.1088/1674-1137/abddb0

## 🛠️ How to Run It
1. Open the `semf1.ipynb` file.
2. Run the cells sequentially to see the results and graphs.
